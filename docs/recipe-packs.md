# Пакеты шаблонов рецептов

Пакет рецептов — JSON-файл с метаданными и одной или несколькими схемами редактора. KubeVS хранит пакеты в `.kubevs/recipe-packs` в корне локальной рабочей области и загружает файлы с суффиксом `.kubevs-pack.json`.

## Создать шаблон

Откройте команду **KubeVS: Create recipe template** или пункт **Recipe templates** на главной вкладке. Вставьте JSON существующего рецепта и нажмите **Read fields**. Укажите имя и ID шаблона, затем отметьте поля, которые должны редактироваться, выберите для них тип редактора и задайте значения по умолчанию. Нажмите **Save template**: шаблон сохраняется в пакете проекта. Неотмеченные поля остаются в исходном JSON и попадут в создаваемые рецепты.

Массивы простых ингредиентов, результатов-предметов и строк автоматически получают подходящие редакторы, если преобразование сохраняет исходный JSON точно. Сложные массивы и объекты остаются полями JSON. При необходимости их можно редактировать целиком.

В мастере **Import pack** устанавливает пакет в текущую рабочую область. **Export pack** сохраняет его в выбранный файл, чтобы передать или хранить отдельно. Один пакет может содержать несколько шаблонов; после импорта их можно выбрать в списке мастера.

## Формат файла

Пакет имеет формат `kubevs-recipe-pack`, версию `1`, namespaced ID, имя и непустой массив схем:

```json
{
  "format": "kubevs-recipe-pack",
  "version": 1,
  "id": "kubevs:my_pack",
  "name": "My recipe templates",
  "schemas": [
    {
      "version": 1,
      "id": "kubevs:my_recipe",
      "label": "My recipe",
      "recipeType": "minecraft:crafting_shapeless",
      "base": {
        "type": "minecraft:crafting_shapeless",
        "ingredients": [{ "item": "minecraft:coal" }, { "item": "minecraft:stick" }],
        "result": { "id": "minecraft:torch", "count": 4 }
      },
      "fields": [
        {
          "path": "ingredients",
          "label": "Ingredients",
          "kind": "ingredient",
          "required": false,
          "multiple": true,
          "minItems": 0,
          "default": ["minecraft:coal", "minecraft:stick"]
        },
        {
          "path": "result.id",
          "label": "Result · Id",
          "kind": "resource_id",
          "required": false,
          "multiple": false,
          "minItems": 0,
          "default": "minecraft:torch"
        },
        {
          "path": "result.count",
          "label": "Result · Count",
          "kind": "integer",
          "required": false,
          "multiple": false,
          "minItems": 0,
          "default": 4
        }
      ]
    }
  ]
}
```

Каждый элемент `schemas` — существующая схема рецепта версии 1. `base` необязателен для прежних схем; когда он есть, KubeVS начинает сборку с его копии и применяет отмеченные поля. Поэтому дополнительные ключи не исчезают из-за того, что им не назначен отдельный редактор. Pack-файл содержит только JSON-данные: он не запускает скрипты и не устанавливает код или VSIX.

Полный пример с рабочим рецептом Minecraft и отдельной синтетической схемой находится в [`examples/recipe-packs/example.kubevs-pack.json`](../examples/recipe-packs/example.kubevs-pack.json). `modid:pressure_chamber` в нём — учебный ID и пример структуры, а не подтверждённый формат рецепта PneumaticCraft или другого мода.

## Использовать через MCP

`kubevs_list_recipe_schemas` показывает установленные схемы. Передайте `schemaId`, чтобы получить полную схему, например `kubevs:vanilla_torch`; без него список можно запрашивать постранично. `kubevs_recipe_schema` принимает выбранную схему и `values`, а затем формирует предварительный просмотр или сохраняет рецепт по обычным правилам записи KubeVS.

MCP-клиент может добавить пакет, вызвав `write_file` для локального root и пути `.kubevs/recipe-packs/<filename>.kubevs-pack.json`. Путь относится к корню открытого проекта. Пакеты из каталога сканируются автоматически, а изменения файлов обновляют каталог схем.

## Границы применения

Шаблон описывает поля JSON и редакторы для них. Он не регистрирует recipe serializer, тип машины или обработчик в Minecraft. Для загрузки рецепта целевой мод должен быть установлен, а JSON должен соответствовать serializer, который он поддерживает. Новый или неподдерживаемый игровой формат шаблон сам по себе не добавляет. Для сложной структуры используйте JSON-поле и проверяйте результат в соответствующей сборке игры.

Прежние схемы версии 1 продолжают загружаться отдельно из `.kubevs/recipe-schemas/*.recipe-schema.json`; формат пакетов дополняет этот способ и не требует переписывать такие файлы.
