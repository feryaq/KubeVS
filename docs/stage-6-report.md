# Отчёт по этапу 6 — LootJS Builder

## Сделано

- Русский визуальный редактор модификаторов таблиц добычи, блоков и сущностей.
- Вложенное дерево AND / OR / NOT с визуальными направляющими.
- Условия шанса, инструмента, убийства игроком, взрыва и пользовательского JSON.
- Действия добавления, удаления, замены добычи и выдачи опыта.
- Строгая проверка сообщений Webview, ID, чисел, глубины, количества узлов и JSON.
- Читаемая генерация `LootJS.modifiers(...)`, live-предпросмотр и безопасный native diff.
- Отдельная команда и действие в заголовке LootJS View.
- Упрощённый сценарий «где менять → что сделать → когда применять» без безымянных полей.
- Добавление действий через один понятный контрол; у ID, количества и шансов есть видимые подписи.
- Сгенерированный JavaScript не занимает рабочее место постоянно и открывается по запросу.
- Правило автоматически получает безопасное имя и сохраняется в generated-папку KubeVS без
  отдельного диалога выбора файла.

## Проверено

- Unit-тесты генерации всех действий и вложенного AND / OR / NOT.
- Тесты целей table, block и entity.
- Отказ на пустых группах, неверном шансе, повторяющихся ID, слишком глубоком дереве и опасном JSON.
- TypeScript, ESLint, Prettier, production bundle и Extension Host через общий `pnpm check`.

## Не заявляется как проверенное

- Выполнение сгенерированного скрипта внутри реальной сборки Minecraft с LootJS.
- Обратный импорт произвольного существующего LootJS JavaScript в дерево.
- Все редкие условия и функции LootJS за пределами пользовательского JSON.
