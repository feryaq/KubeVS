KubeVS 1.5.0 добавляет поддержку машинных рецептов GregTech CEu Modern для Minecraft 1.21.1 в редакторе и MCP. Можно задавать предметы, жидкости, вероятностные выходы, повторно используемые компоненты, схему, длительность, EU/t и условие по высоте. Craft Graph распознаёт формат рецептов GTCEu.

Добавлен навык `kubevs-recipe-design` для осмысленного проектирования крафтов и расчёта производственных цепочек. Он разделяет сложность и лишний гринд, проверяет прогрессию, сырьё, энергию, время и производительность, требует реальные ID и версии модов.

В релиз входят `kubevs-1.5.0.vsix` и `kubevs-connector-1.5.0.jar`. Обновите оба компонента для обнаружения GTCEu через Connector. Для подключения ИИ запустите MCP server в KubeVS и скопируйте конфигурацию штатной командой.

Генерация и тесты не заменяют проверку загрузки рецептов в живом Minecraft с конкретной версией GTCEu.
