# KubeVS 1.8.0

Граф больше не останавливается на 25 000 рецептов: расширение и MCP используют общий загрузчик с проверкой всех страниц и единой ревизии каталога (с Connector 1.8.0), до 250 000 записей и 256 МиБ. В ответе видны размер каталога, число распознанных рецептов, обрезанные ветки, циклы и неразрешённые теги. Полный каталог не означает, что все нестандартные сериализаторы интерпретированы полностью.

Расчёт последовательной сборки Create учитывает вложенные расходуемые ингредиенты и число повторов; переходный предмет не считается внешним ресурсом. Неизвестные типы шагов учитываются как неподдержанные, а не как заведомо бесплатные.

Добавлены `kubevs_patch_recipe` для явного изменения вложенного JSON и `kubevs_verify_recipe` для проверки результата после reload. Перед сохранением проверяются исходные значения и ревизии рецепта и файла. Это обход ограничений `replaceInput` конкретного сериализатора; сама реализация KubeJS не меняется. Диагностика предупреждает, что отсутствие статических ошибок не подтверждает изменение рецепта в игре.

MCP передаёт меньше повторов: граф сохраняет все поля, но общие сведения о рецепте хранит один раз; чтение файлов, рецептов, схем и графов поддерживает `ifRevision`; сохранение не возвращает уже отправленный код без запроса `includeContent`. Полные схемы доступны по умолчанию, обычное вложенное дерево — через `format: tree`. Простой список материалов — отдельный режим `format: resources`. В окне VS Code также можно переключиться с графа на список ресурсов. Это оптимизация данных; конкретная экономия токенов и лимита аккаунта зависит от клиента и работы модели.

Поиск схем заменён ограниченным обходом их папки с параллельным чтением. Для длинных операций убран общий 30-секундный обрыв сокета после получения авторизованного запроса. Клиент MCP может иметь собственный тайм-аут.

Навык крафтов 1.1.0 предлагает выбрать: несколько общих крафтов, связанные ветки или единая прогрессия. До проектирования он изучает назначение модов и их существующие цепочки; после изменения проверяет фактический вложенный JSON живого рецепта.

Разрешение reload по умолчанию остаётся выключенным. Администратор с явным разрешением пользователя может включить его через `kubevs_set_reload_enabled`, затем вызвать `kubevs_reload`.

В релиз входят расширение VS Code и мод Connector для NeoForge 1.21.1. Для применения серверных скриптов нужен KubeJS.
