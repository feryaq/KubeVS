# KubeVS 1.9.0 — собственные форматы рецептов

Теперь KubeVS можно расширять своими файлами `*.kubevs-pack.json`. Один пакет содержит несколько шаблонов, появляется в редакторе рецептов и доступен агентам через MCP.

В **Recipe templates** вставьте JSON существующего рецепта, нажмите **Read fields**, выберите поля формы и сохраните шаблон. Ингредиенты и результаты получают подходящие редакторы там, где преобразование сохраняет исходный рецепт точно. Сложные структуры остаются JSON; неотмеченные поля и условия сохраняются в базе рецепта.

Пакеты можно импортировать, экспортировать и хранить в `.kubevs/recipe-packs`. VS Code проверяет их структуру штатными средствами. Прежние отдельные схемы продолжают работать.

Шаблон описывает уже существующий игровой формат: соответствующий мод должен быть установлен, а его serializer должен принимать полученный JSON. Пакет не добавляет новые машины или обработчики в Minecraft.

В релиз входят расширение **kubevs-1.9.0.vsix** и **kubevs-connector-1.9.0.jar** для Minecraft 1.21.1 / NeoForge. Connector пересобран с общей версией; протокол не изменён.

[Инструкция и пример пакета](https://github.com/Feryaq/KubeVS/blob/v1.9.0/docs/recipe-packs.md).
