KubeVS 1.4.0 добавляет встроенный локальный HTTP MCP-сервер на официальном SDK. Запустите его командами **KubeVS: Start MCP Server** и **KubeVS: Copy MCP Configuration** или откройте управление через карточку MCP server на главной вкладке.

Сервер предоставляет инструменты для текущего проекта и сессии Connector: чтение и редактирование файлов с проверкой ревизий, рецепты и другие KubeJS-генераторы, реестры и журналы, Craft Graph, диагностику и разрешённую перезагрузку скриптов. Генераторы по умолчанию показывают результат без записи.

MCP выключен по умолчанию и ограничен loopback, доверенной рабочей областью и файловой песочницей. Отдельное приложение или демон не устанавливаются; клиент ИИ автоматически не настраивается. Выполнение скриптов в живой игре этим описанием не подтверждается.
