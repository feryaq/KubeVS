KubeVS 1.6.0 обновляет окна рецептов в стиле главного экрана. Ванильные, модовые и schema-рецепты используют общий заголовок, аккуратную форму, компактную навигацию и сворачиваемый предпросмотр кода. Узкие панели поддерживаются до 320 px.

Поддержка GTCEu Modern для Minecraft 1.21.1 расширена: формы для вероятностных и потактовых потоков, диапазонов, EU/CWU, cleanroom, исследований сканера и станции, условий окружения, квестов и служебных данных. Добавлен редактор крафтов 3×3 с инструментами GTCEu и данными для переработки.

Через MCP доступны расширенный генератор машинных рецептов, `kubevs_generate_gregtech_shaped_recipe` и справочник `kubevs://gregtech-guide` с полями, единицами и примерами всех операций. Тип машины выбирается по зарегистрированному recipe type, включая типы сборки. Произвольные Java-объекты сторонних аддонов остаются задачей обычного редактора KubeJS; существующий JSON доступен через общие инструменты чтения и записи.

В релиз входят `kubevs-1.6.0.vsix` и `kubevs-connector-1.6.0.jar`. Сборка и автоматические проверки не заменяют проверку загрузки рецептов в живом Minecraft с установленной версией GTCEu.
