# LootJS Builder

Команда **KubeVS: Создать правило LootJS** открывает визуальный редактор модификаторов добычи. Он
работает офлайн: запущенный Minecraft и KubeVS Connector для генерации файла не нужны. Если
Connector подключён и LootJS на сервере отсутствует, создание правила блокируется с понятным
сообщением — KubeVS не генерирует заведомо неприменимый скрипт.

## Цели

Редактор поддерживает три типа модификаторов:

- таблица добычи — например, `minecraft:chests/simple_dungeon`;
- блок или тег блоков — например, `minecraft:diamond_ore` или `#minecraft:logs`;
- сущность или тег сущностей — например, `minecraft:zombie`.

## Дерево условий

Условия можно вкладывать друг в друга:

- **AND** — должны выполниться все дочерние условия;
- **OR** — достаточно любого дочернего условия;
- **NOT** — инвертирует единственное дочернее условие;
- случайный шанс от `0` до `1`;
- инструмент или тег инструментов;
- убийство игроком;
- предмет пережил взрыв;
- пользовательское JSON-условие Minecraft.

Пользовательский JSON должен быть объектом с полем `condition`. KubeVS ограничивает размер и
глубину дерева, требует уникальные ID узлов и отклоняет поля `__proto__`, `prototype` и
`constructor`.

## Действия

- добавить предмет с количеством и шансом;
- удалить предмет или тег из добычи;
- заменить предмет, при необходимости сохранив количество;
- добавить опыт.

Готовый JavaScript доступен в сворачиваемом блоке предпросмотра и не мешает основному сценарию.
Некорректный ID, шанс, пустая логическая группа или повреждённый JSON блокируют сохранение.

## Сохранение

Файл выбирается автоматически по цели и сохраняется в
`kubejs/server_scripts/kubevs/lootjs`. Диалог **Save As** не показывается. Это managed-файл:
повторное сохранение той же цели обновляет его напрямую и не показывает второй диалог.

Сгенерированный код использует `LootJS.modifiers`, целевой `addTableModifier`,
`addBlockModifier` или `addEntityModifier`, а логическое дерево передаётся через
`matchCustomCondition`.

## Границы текущей проверки

Генератор, валидация, команда VS Code и открытие Webview покрыты автоматическими тестами. Код
сверен с актуальной документацией LootJS для Minecraft 1.21+, но этот релиз не проходил
отдельный игровой тест в сборке с установленным LootJS.
