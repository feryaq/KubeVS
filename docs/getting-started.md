# Getting started

Status: **Foundation / Offline Available**

1. Install dependencies with `pnpm install`.
2. Build with `pnpm build`.
3. Open the repository in VS Code and press `F5`.
4. In the Extension Development Host, open `examples/basic-kubejs`.
5. Select the KubeVS Activity Bar icon.
6. Use **KubeVS: Open Dashboard** or inspect scripts in the Project view.

The mock connection exists for Extension Foundation testing. It does not connect to Minecraft.
