# Персональная авторизация KubeVS Connector

Connector поддерживает два вида учётных данных:

- админ-токен сервера из `config/kubevs-connector-token.txt`;
- личный токен игрока, привязанный одновременно к UUID и текущему нику Minecraft.

## Быстрое подключение игрока

Зайдите на сервер своим Minecraft-аккаунтом и выполните:

```text
/kvs join
```

Команда покажет фактический адрес Connector с настроенным портом и две кликабельные
кнопки: **Копировать токен** и **Копировать адрес**. Вставьте эти значения при
подключении расширения VS Code. Полная форма `/kubevs join` работает так же.

Повторный вызов возвращает тот же токен. Connector сохраняет текущий уровень
прав Minecraft. Если ник или уровень прав аккаунта изменился, Connector заменит
токен, сохранив привязку к UUID. Токен выводится только самому игроку,
не отправляется в общий чат и не записывается в журнал сервера.

По умолчанию `/kvs join` требует уровень прав `2`. Владелец сервера может изменить
`permissions.joinPermissionLevel` в `config/kubevs-connector.toml` в диапазоне `0..4`. Не ставьте `0` на публичном
сервере без дополнительного контроля доступа: личный токен разрешает live-функции Connector,
включая reload, если он включён в конфигурации.

Личные данные хранятся в `config/kubevs-player-tokens.tsv`. Этот файл содержит
секреты: не публикуйте его, не добавляйте в Git и ограничьте доступ к резервным
копиям. Удаление файла отзывает все личные подключения после перезапуска сервера.
Старые трёхколоночные записи читаются как уровень `0`, поэтому обновление не
повышает существующим токенам права автоматически. Игрок повторно выполняет
`/kvs join`, чтобы получить новый токен с актуальным уровнем.

## Команда администратора

Оператор с уровнем прав 4 может выполнить:

```text
/kvs auth
```

Команда всегда показывает реальный порт текущего экземпляра, поэтому при значении
`network.port = 32146` будет предложен адрес с портом `32146`, а не значение по
умолчанию. Кнопки отдельно копируют адрес и админ-токен. Доступны также:

```text
/kvs auth copy
/kvs auth rotate
```

Ротация админ-токена требует отдельного подтверждения и закрывает активные
подключения. Для команд сохранён полный псевдоним `/kubevs`.

## Выделенный сервер и безопасность

По умолчанию Connector принимает только loopback-подключения. Для команды
используйте SSH- или TLS-туннель и оставьте `network.host = "127.0.0.1"`: обычный
`ws://` не шифрует токен. Прямой сетевой доступ включается только при
`network.allowRemote = true` и сетевом значении `network.host`; он требует
отдельно защищённой сети.

После авторизации Connector включает в приветствие тип сессии, UUID и ник игрока
(для личного токена). Серверный файловый контракт, блокировки и защита от
конфликтов описаны в [`team-workspace-api-ru.md`](team-workspace-api-ru.md).
Подключение этого контракта к удалённому workspace VS Code выполняется отдельным
этапом.
