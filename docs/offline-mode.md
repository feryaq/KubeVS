# Offline Mode

Status: **Stable in Foundation**

Without Minecraft or the Connector, KubeVS detects the three standard KubeJS script folders,
indexes JavaScript and TypeScript files, opens them from the Project view, and publishes safe static
diagnostics for open documents.

Live registries, live recipes, game logs, held-item inspection, and reload require the future
authenticated Connector transport. Their views state this limitation without blocking the rest of
the interface.
