# KubeVS 1.1.0 — GitHub release copy

KubeVS 1.1.0 is the first stable public release prepared for Modrinth.

## Highlights

- Visual KubeJS recipe, LootJS, item, and block editors.
- Live Minecraft registries, recipes, tags, mods, logs, and generated typings.
- Craft Graph with smooth draggable nodes, alternatives, and complete resource totals.
- Secure remote KubeJS workspace with roles, locks, revisions, and binary-safe operations.
- Per-player English/Russian runtime localization based on the connected Minecraft client's language.
- Reliable remote recipe creation and live snapshot refresh.

## Install both files

- `kubevs-1.1.0.vsix` — install in Visual Studio Code.
- `kubevs-connector-1.1.0.jar` — place in the NeoForge server's `mods` directory.

Then run `/kvs join` in Minecraft and paste the code into KubeVS in VS Code.

SHA-256 checksums are printed by the release workflow. KubeVS is proprietary commercial software; redistribution requires permission.
