# Проверка KubeVS 1.6.0

## Результат

- `pnpm install --frozen-lockfile`, production audit: успешно, известных уязвимостей нет.
- `pnpm check:release`: метаданные, ESLint, TypeScript, тесты, сборка и Prettier прошли.
- JavaScript: 7 parser + 4 protocol + 12 recipe-model + 74 extension + 3 MCP transport теста; 27 интеграционных тестов в установленном Code OSS на отдельном Xvfb-дисплее.
- Все 55 операций GTCEu имеют форму и пример. Примеры выполнялись с записывающим builder, а затем через настоящий MCP SDK в extension host. Проверены области perTick, числовые границы, исследования, Java factory-вызовы, теги и крафты с инструментами.
- Упакованный minified VSIX отдельно прошёл те же 27 интеграционных тестов в установленном Code OSS.
- Connector: 23 теста без ошибок; production JAR собран Java 21 / Gradle 8.12.1. Из итогового JAR прочитан NeoForge TOML: версия 1.6.0, название KubeVS: VS Code Connector, автор feryaq и полное описание с абзацами.
- Калькулятор навыка проектирования рецептов: 8 тестов успешно.
- Headless Chromium: 66 базовых рендеров, 64/64 проверки действий и layout без ошибок. Новые редакторы проверены при ширине 320, 390, 800 и 1440 px в светлой и тёмной теме. Дополнительные рендеры проверяют формы GTCEu и tool crafting.

## Визуальная приёмка

Осмотрены реальные HTML редакторов из исходников расширения: ванильный при 320 px в тёмной и 1440 px в светлой теме, модовый при 390 px, schema при 1440 px, GTCEu при 800/1440 px и tool crafting при 390 px. Проверены отступы, видимость действий, ширина полей, регистр символов, переполнение и сходство с Home. Исправлены расширение grid-колонки на узких экранах и отображение строчных символов инструментов как заглавных.

Рендеры и подробный JSON-отчёт находятся локально в `artifacts/home-1.6.0/screenshots`. Это HTML реальных webview с тестовыми сообщениями Connector; данные игровой сессии не использовались.

## Границы проверки

Code запускался только на отдельном виртуальном дисплее, Chromium — headless. Пользовательский рабочий стол и фокус окон не использовались. Тесты Connector используют контролируемые fixtures. Реальная загрузка сгенерированных рецептов в Minecraft с GTCEu не проверена; совместимость API сверена с исходниками ветки 1.21, указанными в матрице покрытия. Тестовый builder не заменяет Rhino и игровые registries.

Предупреждения Gradle о будущей версии 9 и сообщение Code Local History при удалении временного dirty-document fixture не сопровождались провалами тестов.
