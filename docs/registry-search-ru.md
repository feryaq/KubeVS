# Поиск и автодополнение игровых ID

KubeVS 0.5.1 использует единый каталог для всех реестров, загруженных текущей сборкой Minecraft:
предметов, блоков, жидкостей, сущностей, структур, биомов и реестров модов.

## Поиск из Activity Bar

Откройте **KubeVS → Реестры → Найти игровой ID**. Сначала выберите тип объекта, затем вводите:

- имя в игре: `Алмаз`;
- часть ID: `diamond`;
- полный ID: `minecraft:diamond`;
- translation key, если он доступен от Minecraft.

После выбора KubeVS копирует ID в буфер обмена.

## Визуальные редакторы

Кнопка `⌕` рядом с игровым ID открывает тот же нативный поиск VS Code. Она доступна в:

- Vanilla Recipe Editor;
- редакторе Create, Oritech и Farmer’s Delight;
- Generic Recipe Editor для полей `ingredient`, `item_stack` и `resource_id`;
- LootJS Builder для целей, инструментов и действий с добычей.

Для ингредиентов и фильтров каталог также показывает теги с префиксом `#`.

После выбора предмета KubeVS показывает его настоящую игровую текстуру рядом с ID. Иконки
загружаются через Connector 0.3.0 из ресурсов Vanilla и установленных модов. Для тегов и объектов
без доступной клиентской текстуры поле остаётся без иконки.

Рецепты сохраняются без диалога выбора файла в каталог из настройки
`kubevs.generatedFiles.directory`. По умолчанию это
`kubejs/server_scripts/kubevs`. При перезаписи существующего файла безопасный diff
остаётся обязательным.

## Автодополнение в коде

В строках JavaScript, TypeScript, JSON и JSONC начните вводить имя или ID:

```js
Item.of('алм');
Item.of('minecraft:dia');
```

Список показывает отображаемое имя и точный ID, а вставляет `namespace:id`.

## Live и Offline Mode

С Connector 0.3.0 KubeVS выполняет поиск сразу по всем загруженным реестрам. Для предметов,
блоков и сущностей используются реальные локализованные имена Minecraft; для остальных типов
показывается читаемое имя, сформированное из зарегистрированного ID.

Без подключения KubeVS:

- находит ID в открытых JS, TS и JSON-файлах проекта;
- предлагает основные Vanilla ID;
- помечает результат как офлайн-подсказку.

Старый Connector 0.1.1 остаётся совместимым, но отдаёт только ID. Для реальных отображаемых имён
установите Connector 0.3.0.
