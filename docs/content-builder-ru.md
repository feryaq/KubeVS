# Item и Block Builder

Команды `KubeVS: Создать предмет` и `KubeVS: Создать блок` открывают простой визуальный
конструктор содержимого KubeJS.

## Основной сценарий

1. Укажите читаемое название в игре.
2. KubeVS автоматически создаст технический ID в пространстве `kubejs`.
3. При необходимости выберите существующий предмет или блок как иконку-образец.
4. Настройте размер стака, редкость и подсказку либо свойства блока.
5. Проверьте сгенерированный KubeJS и сохраните его через безопасный diff.

Файл создаётся в `startup_scripts/kubevs`. Новый предмет или блок появится только после
полного перезапуска Minecraft. Кнопка `Изменить` рядом с ID оставляет возможность задать его
вручную.

Иконка нужна для наглядного предпросмотра. KubeVS не копирует сложную модель как выдуманный путь
текстуры: это защищает от missing texture у зелий, яиц призыва и модовых предметов.

## Контрольный контент Connector

Connector 0.4.0 регистрирует:

- `kubevs:debug_item` — отладочный предмет;
- `kubevs:debug_block` — отладочный блок;
- крафт 3×3 из девяти отладочных предметов в блок;
- обратный бесформенный крафт блока в девять предметов.

Оба объекта находятся во вкладке ингредиентов творческого режима. Их также можно получить через
`/give @s kubevs:debug_item` и `/give @s kubevs:debug_block`.
