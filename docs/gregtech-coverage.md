# GTCEu Modern · Minecraft 1.21.1

API сверялся с официальной веткой `1.21`, коммит [`36a6b38c580e54445e055e3ca05eecf675f2cb96`](https://github.com/GregTechCEu/GregTech-Modern/tree/36a6b38c580e54445e055e3ca05eecf675f2cb96). Это граница совместимости генератора, а не обещание совместимости со всеми будущими версиями и сторонними Java-аддонами.

| Возможность                              | Редактор и MCP                                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Зарегистрированные машинные recipe types | Имя типа в поле Recipe type; не фиксированный список машин                                                                       |
| Предметы, теги, компоненты, альтернативы | Строки KubeJS с component filter; операция Alternative items                                                                     |
| Жидкости и жидкостные теги               | mB; теги поддерживаются на входе и для катализаторов                                                                             |

| Данные рецепта                           | Строка, число, boolean, Compound SNBT                                                                                            |

`Advanced GTCEu` использует обычные поля формы. MCP-ресурс `kubevs://gregtech-guide` содержит тот же каталог: операция, допустимые поля, типы и готовый пример. Неизвестные операции и поля отклоняются. Строки не исполняются как JavaScript; генератор использует фиксированный список вызовов и фабрик классов.

Инструменты: `s` — пила, `h` — молот, `r` — мягкая киянка, `w` — ключ, `f` — напильник, `c` — лом, `d` — отвёртка, `m` — ступка, `x` — кусачки, `k` — нож. Строчные символы назначает сам GTCEu; пользовательские ингредиенты задаются другими символами.

В GTCEu нет универсального встроенного поля «давление» для всех машин. Параметры конкретного аддона передаются через его реальные data/condition API; KubeVS не выдумывает для них методы. Создание новых типов машин, собственных Java capability/condition и произвольных callback остаётся в штатном редакторе VS Code. Дополнительные сериализуемые форматы можно редактировать через schema-рецепты и общие инструменты MCP.

Длительность задаётся в тиках, жидкости — в mB, температура — в K, энергия — EU/t или EU согласно полю. Значения Java int ограничены 2147483647; long ограничен точностью безопасных целых JavaScript. IDs, наличие тегов, data-item components и доступность исследований окончательно проверяет установленная игра. Автоматические тесты генерации и MCP не равны успешной загрузке рецепта в Minecraft.
