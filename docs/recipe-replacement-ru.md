# Быстрая замена рецепта

Команда **KubeVS: Заменить рецепт другим** создаёт замену без ручного выбора файла:

1. выберите ID рецепта, который нужно заменить;
2. выберите существующий рецепт-шаблон;
3. подтвердите действие кнопкой **Заменить по ID**.

KubeVS получает определение шаблона через Connector, но генерирует его с ID первого рецепта.
Поэтому замена выполняется строго по recipe ID, а не по предмету-результату. Рецепты с одинаковым
результатом не затрагиваются.

Managed-файл автоматически попадает в соответствующую папку:

```text
server_scripts/kubevs/crafts/vanilla
server_scripts/kubevs/crafts/create
server_scripts/kubevs/crafts/oritech
server_scripts/kubevs/crafts/farmersdelight
server_scripts/kubevs/crafts/generic
```

Исходные JSON и файлы модов не меняются. Повторная замена того же ID обновляет managed-файл
напрямую, без окна Save As. После проверки кода выполните **KubeVS: Сохранить и перезагрузить**.

Команда требует активного подключения к KubeVS Connector, поскольку список и определения рецептов
берутся из запущенного Minecraft или dedicated server.
