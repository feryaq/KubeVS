# Редактор рецептов Create, Oritech и Farmer’s Delight

Команда **KubeVS: Создать рецепт Create / Oritech / Farmer’s Delight** открывает единое рабочее
место для рецептов популярных модов. Редактор работает офлайн и не требует запущенного Minecraft.

## Поддерживаемые типы

### Create

- механическое прессование, дробление колёсами и помол на жерновах;
- механическое смешивание и прессование в бассейне с уровнем нагрева;
- механическая резка и установка манипулятором;
- последовательная сборка.

Механическое смешивание и прессование в бассейне поддерживают отдельные предметные и жидкостные
входы и результаты. Жидкость выбирается из реестра `minecraft:fluid` по игровому имени или ID.
Объём задаётся в миллибакетах (`mB`): `1000 mB` равны одному ведру. Во входе можно использовать
конкретную жидкость (`minecraft:water`) или тег (`#c:milk`); жидкостный результат всегда указывает
конкретную жидкость.

Для Sequenced Assembly доступна timeline: шаги можно добавлять, удалять и переставлять. Установка
поддерживает дополнительный предмет или тег, а прессование и резка работают с переходным
предметом. Редактор также сохраняет число циклов и несколько результатов с весами.

### Oritech

- assembler;
- pulverizer и grinder;
- centrifuge;
- foundry;
- atomic forge.

Для машин задаются входы, несколько результатов и время обработки в тиках.

### Farmer’s Delight

- cooking;
- cutting.

Готовка поддерживает ингредиенты, результат, опыт и время. Разделочная доска поддерживает
инструмент или тег инструментов и несколько результатов.

## Формат полей

- обычный предмет: `minecraft:iron_ingot`;
- тег: `#c:ingots/iron`;
- жидкость: `minecraft:water`;
- тег жидкости: `#c:milk`;
- объём жидкости: целое число больше нуля в `mB`;
- ID рецепта: `namespace:path`;
- шанс `1` означает гарантированный результат;
- в Sequenced Assembly значение шанса используется как вес результата и может быть больше `1`.

## Сохранение

KubeVS создаёт читаемый вызов `event.custom(...)` внутри `ServerEvents.recipes`. Файл по умолчанию
сохраняется автоматически в папку интеграции:

```text
kubejs/server_scripts/kubevs/crafts/create
kubejs/server_scripts/kubevs/crafts/oritech
kubejs/server_scripts/kubevs/crafts/farmersdelight
```

Выбирать файл вручную не нужно. При подключении к Connector редактор определяет установленные
моды и блокирует типы рецептов отсутствующих интеграций. В Offline Mode все встроенные редакторы
остаются доступны, потому что состав будущей игровой сборки неизвестен.

Если целевой файл уже существует, KubeVS:

1. создаёт временную предлагаемую версию;
2. открывает native diff VS Code;
3. требует явного подтверждения;
4. повторно проверяет, что исходный файл не изменился во время просмотра.

Без подтверждения пользовательский файл не перезаписывается.
