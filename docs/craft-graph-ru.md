# Craft Graph и калькулятор ресурсов

Команды **KubeVS: Открыть Craft Graph** и **KubeVS: Рассчитать ресурсы** используют реальные
рецепты подключённой сборки Minecraft.

## Работа с деревом

1. Выберите предмет по имени или ID.
2. Укажите требуемое количество и глубину расчёта.
3. Нажмите **Рассчитать**.
4. Раскрывайте и сворачивайте производственные ветви.
5. Если для предмета найдено несколько рецептов, нажимайте кнопку `1 / N рецептов`, чтобы
   переключать альтернативный путь.

Левая панель показывает итоговые базовые предметы и жидкости, суммарное время и энергию. Правая
панель показывает точный ID рецепта, тип машины, количество операций и побочные продукты выбранного
узла.

Шансовые результаты рассчитываются по ожидаемому выходу. Например, результат с шансом 50% и
количеством 2 считается как один предмет на операцию. Реальный случайный результат внутри игры
может отличаться.

## Offline Mode

При успешном подключении snapshot сохраняется в `.kubevs/cache/recipe-snapshot.json`. После
отключения дерево продолжает работать с последним snapshot. Кнопка `↻` обновляет данные из
Minecraft.

Для пользовательских и редких модовых форматов KubeVS ищет стандартные поля `ingredient`,
`ingredients`, `input`, `result`, `results`, `fluid`, `count`, `chance`, `processingTime` и
`energy`. Неизвестный формат остаётся в snapshot, но не включается в расчёт, пока для него не будет
добавлен нормализатор.
