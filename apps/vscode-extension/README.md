# KubeVS для Visual Studio Code

KubeVS превращает Visual Studio Code в рабочую среду для KubeJS. Расширение индексирует проект, предлагает дополнение кода, подсказки, диагностику и Code Actions, а также предоставляет визуальные редакторы рецептов, правил LootJS, предметов и блоков.

Расширение бесплатно: подписки, платных функций, лицензионных ключей и платы за использование нет.

Подключите KubeVS Connector, чтобы просматривать реестры и рецепты игры, разбирать производственные цепочки в Craft Graph и открывать всю серверную папку `kubejs` в Explorer. Совместная работа учитывает роли, блокировки файлов и ревизии; файлы передаются с сохранением бинарных данных.

В Minecraft выполните `/kvs join`, затем в VS Code запустите **KubeVS: Connect with /kvs join code**. Интерфейс расширения пока доступен на английском. В автономном режиме остаются доступны локальные редакторы и диагностика.

Для удалённого сервера используйте VPN или WSS через TLS reverse proxy. По умолчанию Connector принимает подключения только с localhost, а учётные данные расширение хранит в VS Code SecretStorage.

KubeVS распространяется по лицензии [KubeVS Community Source License 1.0](../../LICENSE). Созданные файлы проекта остаются вашими; условия использования исходного кода и распространения описаны в лицензии.

## Рабочая среда 1.4

Главная вкладка объединяет визуальные редакторы, поиск инструментов, последние файлы проекта и состояние подключения к Minecraft. В редакторах можно копировать готовый JavaScript и сохранять его сочетанием Ctrl/Cmd+S.

Редактор Create: mechanical crafting позволяет задать шаблон размером до 9×9, сопоставить символы с предметами или тегами ингредиентов и выбрать значение обязательного булева поля `accept_mirrored`. Результат формируется как событие KubeJS `event.custom` с типом `create:mechanical_crafting` и полями `pattern`, `key` и `result`.

Браузер реестров поддерживает постраничный поиск, копирование ID и просмотр элементов тегов. Craft Graph показывает копируемый список ресурсов с единицами жидкостей и адаптирует панели ресурсов и сведений к ширине окна. Импорт JSON рецепта создаёт читаемый KubeJS-код и показывает различия при перезаписи; просмотр предмета в руке копирует его ID из личной сессии Connector. Проверка подключения измеряет задержку и, если доступно, запрашивает состояние Connector.

Статическая проверка учитывает комментарии, строки, регулярные выражения и подстановки в шаблонных строках. Она выполняет полезный лексический анализ, но не проверяет корректность полного выполнения JavaScript.

## Пакеты шаблонов рецептов

Создайте схему командой **KubeVS: Create recipe template** или через **Recipe templates** на Home: вставьте JSON рецепта, нажмите **Read fields**, задайте имя и ID, выберите checkbox для полей, их editor kind и defaults, затем сохраните шаблон. Пункт **Import pack** устанавливает пакет, а **Export pack** сохраняет его для передачи. Один файл может содержать несколько шаблонов.

Пакеты `*.kubevs-pack.json` в `.kubevs/recipe-packs` описаны в [руководстве по формату, мастеру и MCP](../../docs/recipe-packs.md). Шаблон хранит исходный рецепт в `base`, поэтому поля вне формы остаются в JSON. Простые ингредиенты и результаты получают специализированные поля; сложные структуры остаются JSON.

Пакет содержит только данные. Он не устанавливает recipe serializer или тип машины: целевой мод должен быть установлен, а JSON — поддерживаться его serializer. Синтетический `modid:pressure_chamber` в примере предназначен только для обучения и не подтверждает формат PneumaticCraft.

## MCP-сервер

Расширение включает локальный HTTP MCP-сервер на официальном SDK. Включите его командой **KubeVS: Start MCP Server**; карточка MCP server на главной вкладке открывает управление через native Quick Pick. Команда **KubeVS: Copy MCP Configuration** копирует пример настроек клиента. По умолчанию MCP выключен (`kubevs.mcp.enabled: false`), слушает `127.0.0.1:32146/mcp`; порт `0` выбирает свободный автоматически. Ключ хранится в VS Code SecretStorage.

Инструменты MCP используют ту же сессию Connector, что и открытый интерфейс KubeVS. Они могут читать и изменять локальные и удалённые файлы KubeJS с контролем ревизий, работать с JSON- и Create-рецептами, LootJS, стартовыми предметами и блоками, схемами, просмотром/удалением/восстановлением/заменой рецептов, реестрами, тегами, списком модов и журналами, блокировками, предметом в руке, Craft Graph, диагностикой и разрешённой перезагрузкой скриптов. Генератор по умолчанию возвращает предварительный просмотр без записи (`save: false`); для создания файла передайте `save: true`. Перезапись требует ожидаемую ревизию из `read_file`. Регистрации, выполняемые при запуске, вступают в силу после перезапуска игры или сервера; перезагрузка рецептов и LootJS выполняется только явным запросом при наличии разрешения Connector.

Сервер доступен только на loopback и требует ключ Bearer. Он работает в доверенной рабочей области, ограничивает файловый доступ папкой проекта и файлами KubeJS Connector, принимает только UTF-8 до 512 КиБ и отклоняет запросы с browser origin. MCP не выполняет произвольные команды, shell или доступ к произвольным путям и не раскрывает токены Connector. Это часть расширения: отдельное приложение или демон не устанавливаются. Клиент ИИ автоматически не настраивается. Для SSH-подключения сервер слушает loopback на удалённой машине, где запущен extension host; MCP-клиент должен иметь сетевой путь к этой машине, например через SSH-туннель. Примеры настроек — в [руководстве MCP](../../docs/mcp.md).

### GregTech CEu Modern · Minecraft 1.21.1

В **Mod recipe → GregTech CEu** создавайте машинные рецепты и крафты с инструментами. Машина выбирается из списка, время задаётся в секундах, питание — уровнями; жидкости и шансы добавляются по необходимости. **Advanced GTCEu** содержит формы потоков IO, EU/CWU, исследований сканера и станции, условий окружения, cleanroom, квестов и служебных данных. Тип машины задаётся именем зарегистрированного recipe type. Для ИИ доступны `kubevs_generate_gregtech_recipe`, `kubevs_generate_gregtech_shaped_recipe` и каталог `kubevs://gregtech-guide`. Произвольные Java-объекты сторонних аддонов остаются в обычном редакторе KubeJS. Автоматические проверки генерации не заменяют загрузку рецептов в Minecraft с конкретной версией GTCEu.

Администратор Connector 1.7.0+ может разрешить reload через `kubevs_set_reload_enabled`, затем применить рецепты через `kubevs_reload`. Это перезагрузка ресурсов, не перезапуск Minecraft.
